# Blackjack
A simple implementation of Blackjack in Python developed as a personal project to practise writing object-oriented code in a clear and well-structured way.

## Current version
- Command line Blackjack with core game rules
- Dealer's second card is hidden until the player has finished their turn
- Dealer hits on a soft 17
- Supports any number of decks in shoe
- Player and dealer logic with standard outcomes
